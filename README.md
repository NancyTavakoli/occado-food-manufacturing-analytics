# Occado Food Manufacturing Analytics

ETL pipeline and Power BI dashboard for analysing
food manufacturing waste and delivery performance.

## Data
- 150 CSV source files

## Pipeline
1. Staging: CSV files loaded into SQL Server staging tables (T-SQL)
2. Transformation: cleaning and standardising data in T-SQL
3. Model: Star Schema in Power BI
4. Reporting: DAX measures and dashboard pages

## Tools
T-SQL, Power BI, DAX, Python (pandas)
